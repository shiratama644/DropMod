## 3. 初回 CI 失敗の原因と修正 (dispatch `33467761928`)

3 テストのみ失敗 (modDetailGallery / versionFilter / discoverSkeleton は初回で green)。

| テスト | 失敗内容 | 原因 | 修正 |
|---|---|---|---|
| profileMods (desktop/mobile) | `getByLabel('E2E Sodium を選択')` が strict mode violation (2 要素) | DesktopTable と MobileList の**両方**が同名 `aria-label` のチェックボックスを持つため。`md:` で片方は非表示だが getByLabel は非表示要素も解決対象 | `input[aria-label=…]:visible` で表示側のみに絞る `rowCheckbox()` ヘルパー |
| folderImportCopy (desktop) | 解析結果内に `Minecraft 1.21.1` が見つからない | 環境行アサーションを regex から、既存 folderImport.spec と同一の文字列一致 (ENV_FIXTURE 由来の完全行) に変更。失敗時は解析結果の実 innerText を `DIAG[analysis]` として先頭 200 字に出力 | `9527e46` |

※ folderImportCopy の環境行は regex でも正しく書けていたが、初回 run では実テキストが
異なっていた可能性が残るため、次回失敗時の自己診断を組み込んだ形にした (最終 run は green)。
